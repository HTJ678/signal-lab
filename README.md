# Signal Lab · 谐波合成器

**把傅里叶级数看得见、听得见。**

选一个波形，拖动"保留前 N 个谐波"，然后看三件事同时发生：

- **时域**：波形被谐波一层层拼出来——能亲眼看到跳变处的**过冲（吉布斯现象）**怎么都不肯消失
- **频域**：幅度谱柱状图，方波"只有奇次谐波"、三角波 1/n² 衰减、脉冲串的 sinc 包络一眼可见
- **听觉**：谐波越少越闷，越多越接近理想波形

纯静态网页，无框架、无打包、无依赖；FFT 是手写的。

## 玩之前

需要一个本地静态服务器（`file://` 打不开音频上下文，浏览器会拦）：

## 两个实验

| 页面 | 内容 |
| --- | --- |
| `index.html` | **谐波合成器**：选波形 + 截断谐波数，看时域/频域/声音同步变化 |
| `pulse.html` | **门函数 ⊛ 冲激串**：周期脉冲串是怎么"造"出来的——时域卷积 ↔ 频域相乘 |

## 波形与它们的傅里叶系数

| 波形 | 谐波构成 | 衰减 |
| --- | --- | --- |
| 正弦波 | 只有基波 | — |
| 方波 | 只有奇次（1, 3, 5, …） | 1/n |
| 锯齿波 | 全部谐波 | 1/n |
| 三角波 | 只有奇次 | **1/n²**（所以听起来最软） |
| 脉冲（25% 占空比） | 包络是 sinc 函数，每第 4 根正好为零 | — |

统一写成 `x(t) = dc + Σ ampₙ·cos(2πnt + φₙ)`，周期归一化到 `t ∈ [0,1)`。

## 几个可以自己验证的结论

- **时域卷积 = 频域相乘**：周期脉冲串 = 门函数 ⊛ 冲激串。门函数的谱是 `sinc`，冲激串的谱还是冲激串，相乘就是"用 sinc 包络去取样一根根梳齿"——这正是 `pulse.html` 里那两个画面
- **主瓣宽度 = 1/τ**：门越窄，包络越宽，谐波越多（时宽与带宽成反比）
- **方波 → 方波**：谐波越多，波形越方；但跳变处的峰值永远停在约 **1.179 倍**（过冲约占半跳变的 8.95%），这就是吉布斯现象
- **三角波比方波"软"**：同样是奇次谐波，但 1/n² 衰减意味着高次谐波几乎没了
- **脉冲需要宽的频谱**：25% 占空比时每第 4 根谐波为零（`sin(πnd)=0`），这是"时域越窄、频域越宽"的直观演示
- **FFT 是对的**：单元测试用 Parseval 定理（时域能量 = 频域能量）和"单频信号的频谱是单根尖峰"两条来验收

## 声音是怎么来的

不用采样、不用素材：把当前的傅里叶系数直接交给 Web Audio 的
`createPeriodicWave(real, imag)`，浏览器就按这组系数合成出一个带限波形。
所以"拖动滑块"本质上是在**实时改一组傅里叶系数**。
