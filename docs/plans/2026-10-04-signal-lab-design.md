# Signal Lab · 谐波合成器 — 设计文档

- **日期**：2026-10-04
- **状态**：已确认并实现（v0.1）

## 目标

把"傅里叶级数"从公式变成**能看、能听**的东西，作为作品墙上第二件作品；同时服务于小侯的 838《信号与系统》复习。

**成功标准**：打开 30 秒内，看到一个方波被奇次谐波一层层拼出来，并且能听到"谐波越多越亮"。

## 范围（v1 只做一个模块）

**做**：波形选择（正弦 / 方波 / 锯齿 / 三角 / 脉冲）+ 保留谐波数滑块 + 时域波形 + 幅度谱 + 声音。
**不做**（留给后续版本）：采样与混叠、卷积动画、滤波器、z 变换。

## 关键决策

| 决策 | 理由 |
| --- | --- |
| 统一用 `x(t) = dc + Σ ampₙcos(2πnt + φₙ)` 表示所有波形 | 合成、频谱图、音频三处读同一组数字 |
| **手写 FFT**（不引库） | 目标是"讲得清"，用库等于跳过要学的东西 |
| 声音用 `createPeriodicWave(real, imag)` | 直接把傅里叶系数交给浏览器合成，滑块 = 实时改系数，概念最干净 |
| 数学层与 DOM/音频彻底分离 | 15 个单元测试全部跑在 Node 里，不需要浏览器 |
| 时域同时画理想波形（虚线）与合成波形（实线） | "逼近"这件事必须能直接看见 |

## 已验证的数学结论（都有测试兜底）

- 方波：仅奇次谐波，1/n 衰减；三角波：仅奇次，1/n² 衰减
- 锯齿波：全部谐波，符号交替（表现为相位差 π）
- 25% 脉冲：包络为 sinc，每第 4 根谐波为零
- **吉布斯现象**：峰值随谐波数收敛到约 **1.179**（过冲 = 半跳变的 8.95%），且从上方逼近
- **FFT 正确性**：冲激 → 平坦谱；常量 → 能量全在 bin 0；单频 → 单根尖峰；**Parseval 定理**成立；长度非 2 的幂时报错

## 已知限制

- 只画前 2 个周期、最多 64 个谐波
- 音频使用浏览器的 `PeriodicWave`（自带带限），所以极高谐波在听感上会与图形略有差异
- 没有做移动端专门的触摸优化（滑块可用，画布自适应）

## 路线图

1. 采样与混叠：可调采样率 + 重建 + 混叠频率标注
2. 卷积：两个信号的卷积动画（配 LTI 说明）
3. 滤波器：低通/高通/带通，看频谱被削 + 听变化
4. 拉普拉斯 / z 变换可视化
